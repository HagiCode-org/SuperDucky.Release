# SuperDucky.Release

[English](./README.md)

SuperDucky(超级丫丫)发行版的公开下载镜像。SuperDucky 是一款面向 Unity 游戏的跨平台桌面模组管理器,支持逃离鸭科夫和深空当铺(Probably Stolen)。

**[官网](https://sd.hagicode.com/)** · **[Microsoft Store](https://apps.microsoft.com/detail/9ndbtdkqbx30)** · **[发行版](https://github.com/HagiCode-org/SuperDucky.Release/releases)**

## 功能一览

### 模组管理

在同一个列表里启用、停用和排序模组,支持拖拽排序和分组排序。

![模组管理页动态示意图](images/mod-management-zh.gif)

### 加载顺序

开始游戏之前,先发现依赖和顺序上的问题。

![加载顺序页动态示意图](images/load-order-zh.gif)

### 分组

把模组归入分组,并给分组排序。

![模组分组动态示意图](images/groups-zh.gif)

### 套件

把每套模组配置保存为套件,随时切换。

![模组套件动态示意图](images/suites-zh.gif)

### 市场

不离开应用,直接浏览 Steam 创意工坊的模组。

![市场页动态示意图](images/market-zh.gif)

### 存档编辑(即将推出)

在同一个地方编辑存档。该功能尚未发布。

![存档编辑动态示意图](images/save-editing-zh.gif)
